# 项目简介

这不是一篇 Arch Linux 安装教程。

这是一份我在使用 Arch Linux 过程中，**遇到的各种问题、排查思路与底层原理**的记录。从实用角度出发，记录每一次踩坑后的思考与解决过程。

> 如有错误欢迎指出，有更好的方案欢迎分享交流。

## 写给读者的一段话

我使用 Arch Linux 的过程中，查阅了大量资料，深感中文互联网上关于桌面 Linux 的优质内容仍然稀缺——要么停留在安装步骤的复述，要么过于碎片化。

很多文章告诉你"怎么做"，但很少告诉你"为什么要这么做"。

这个仓库的初衷是记录我自己的笔记，但如果能帮助到同样在探索桌面 Linux、不满足于"照抄命令"的朋友，那便是额外的价值。

**本仓库不讲"怎么装"，只讲"安装后遇到了什么问题，以及背后的原因是什么"。**
